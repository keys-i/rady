# Rady moved to Pekin

The project is now [Pekin](https://github.com/keys-i/rady). Install the maintained CLI:

```sh
cargo install pekin --locked
pekin --help
```

This final `rady` package only prints the move notice. It does not run Pekin or move your saved runs and configuration. If you use the GitHub App, follow the [upgrade guide](https://github.com/keys-i/rady/blob/main/docs/UPGRADING.md) to reconnect under the Pekin name.
