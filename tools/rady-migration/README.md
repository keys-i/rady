# Rady moved to Koelu

The project is now [Koelu](https://github.com/keys-i/rady). Install the maintained CLI:

```sh
cargo install koelu --locked
koelu --help
```

This final `rady` package only prints the move notice. It does not run Koelu or move your saved runs and configuration. If you use the GitHub App, follow the [upgrade guide](https://github.com/keys-i/rady/blob/main/docs/UPGRADING.md) to reconnect under the Koelu name.
